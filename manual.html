1 System Overview & Architecture

Rison WorkTrack is an enterprise operations and task management system built specifically for Bharat Loomtex. It provides unified daily task assignment, project milestone management, real-time work timers, shift attendance auditing, and mathematically sound productivity reports.

🌐 Dedicated Branded Portal
Live at https://bharatloomtex.risonaitech.com with zero third-party platform branding and automatic enterprise-grade SSL encryption.
⚡ Real-Time Cloud Synchronization
Powered by high-speed Vercel persistent storage with origin cache bypass (useCache: false). Changes made by leadership or staff sync instantly across all devices.
⏱️ Anti-Fraud Concurrency Lock
Guarantees employees cannot log multiple tasks in parallel. Starting a second timer cleanly pauses the first, preserving authentic work audit trails.
📊 Mathematical Performance Scoring
Replaces arbitrary managerial ratings with a 4-factor formula (30% Completion + 30% On-Time + 25% Quality + 15% Work Consistency).

3

3.2 Automatic Shift Clock-In & Clock-Out Tracking

To measure daily work duration transparently without invasive surveillance, WorkTrack ties shift attendance to verified active sessions:

🟢 Clock-In (On Login)
The moment an employee logs into the portal, the system opens an active shift session. The login timestamp and date are saved to the attendance ledger.
🔴 Clock-Out (On Logout)
When the employee clicks Log Out in the top navigation bar, the system cleanly closes their shift session, pauses any active task timer, calculates total shift hours, and redirects to the logout confirmation page.

4 Task Orchestration Guide (MD & Director)

Executive leadership can create, schedule, prioritize, and assign deliverables with precision.

4.1 Creating a New Task

1
Open the Task Assignment Modal
Click the blue "Assign New Task" button located on the top right of the Admin Dashboard or Task Management page (/admin/tasks).
2
Specify Title, Description & Scope
Enter an actionable title (e.g. "Panipat Loom Maintenance Ledger Audit") and full scope instructions in the description box.
3
Select Task Type & Project
Choose Daily Task for routine work, or Project Task and link it to an active corporate initiative (e.g. Winter Jacquard Weaving Run).
4
Assign Personnel, Priority & Target Deadline
Select the assignee from the authorized personnel list, set the priority level (LOW, MEDIUM, HIGH, URGENT), set the completion deadline date, and input estimated hours.
5
Publish & Dispatch
Click "Create & Assign Task". The task immediately appears in the employee's workspace and sends a new task notification.

4.2 Navigating the Three Unified Task Views

  • List View: Detailed tabular data showing assignee cards, priority, status badges, deadlines, logged vs. estimated hours, and real-time progress bars.
  • Kanban Board: 5 stage columns: Not Started → In Progress → On Hold / Blocked → Submitted for Review → Completed. Cards can be opened with one click.
  • Calendar View: Month grid plotting deliverable deadlines so management can foresee workload bottlenecks.

6 Task Timer & Concurrency Safety Lock

Employees can track exact work hours on any assigned task using the built-in precision timer widget.

▶️ Start & Pause Controls
Click Start Timer to begin recording time. Click Pause when taking breaks. Total elapsed duration is converted to decimal hours automatically.
🔒 Concurrency Safety Lock
An employee can only have one active timer running. Starting a timer on Task B automatically pauses Task A and saves its logged hours cleanly.

8 Productivity Scoring Formula

WorkTrack utilizes a transparent, four-factor mathematical scoring index to evaluate employee performance without arbitrary managerial bias.

Performance Score = (0.30 × Completion Rate) + (0.30 × On-Time Rate) + (0.25 × Quality Rate) + (0.15 × Work Consistency)
Metric Component Weight Mathematical Definition Business Impact
Completion Rate 30% (Completed Tasks / Total Assigned Tasks) × 100 Measures overall delivery volume against assigned operational responsibilities.
On-Time Delivery Rate 30% (Tasks Completed On or Before Due Date / Total Completed Tasks) × 100 Rewards adherence to plant production deadlines and financial schedules.
Quality / Approval Rate 25% (Submissions Approved Without Rejection / Total Review Submissions) × 100 Measures accuracy and reduces rework; penalizes tasks returned for corrections.
Work Progress Consistency 15% Average progress percentage updated regularly across active workload Encourages steady daily progress updates rather than last-minute rushing.
🌟 Star Performer (80% – 100%)
High delivery volume, zero overdue tasks, and work approved on initial submission.
🟢 On Track (60% – 79%)
Solid performance meeting all standard operational and production expectations.
⚠️ Needs Support (< 60%)
Workload bottleneck detected or multiple deadlines missed; requires management assistance.

12 Frequently Asked Questions (FAQ)

Q: What happens if an employee forgets to stop their timer?
A: When logging out at the end of the shift, the system automatically stops and finalizes any active timer safely.

Q: Can employees see tasks assigned to colleagues?
A: No. Strict role isolation ensures employees can only view and access their own assigned deliverables.

Q: How long is task data stored in the cloud?
A: Data does not expire. All records, time logs, and comments are stored permanently in Vercel Cloud Storage.
